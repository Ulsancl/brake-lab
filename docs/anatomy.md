# 브레이크 · ABS 구조 관찰

이 모델은 특정 차량이나 제조사의 CAD를 재현하지 않은 일반 구조 설명용 형상입니다. 모든 형상과 표면은 자체 제작했으며 제조사 이미지·모델·카탈로그 형상을 앱 자산으로 복제하지 않았습니다. 좌표 단위는 m, 로터 회전축은 +Z, 위쪽은 +Y입니다.

## 연결된 부품

통풍 로터는 두 주철 마찰판과 사이의 36개 베인, 중앙의 허브 연결부로 구성됩니다. 판 사이 통풍 공간은 실제 빈 형상입니다. 허브에는 플랜지·휠 스터드·중앙 고정부를 표시합니다. 너클 지지부에는 허브 베어링의 고정 외륜이 있고, 안쪽에서는 허브 회전측을 지지합니다. 베어링의 내외륜·볼·밀봉부도 구분합니다. 볼의 개별 구름 운동과 내부 마찰은 계산하지 않습니다.

패드에는 마찰재와 금속 백플레이트가 있습니다. 캘리퍼는 실린더 보어·피스톤 뒤 유압실·두꺼운 브리지·가공 접합면으로 구성합니다. 피스톤 주변에는 보어 홈의 사각 단면 실과 더스트 부츠를 따로 표시합니다. 유압 호스는 외부 유압모듈과 캘리퍼에 연결되고, 블리더는 유압실의 공기를 빼는 위치를 나타냅니다. 모델의 유로는 연결 관계를 설명하는 대표 경로이며 제조용 내부 드릴링 도면은 아닙니다.

**플로팅형**은 한쪽 피스톤이 안쪽 패드를 밀고 몸체가 두 가이드 핀을 따라 반대쪽으로 움직이며 바깥 패드를 누릅니다. 고정 브래킷, 몸체 슬라이드 핀과 핀 부츠를 분리합니다. **고정형**은 몸체가 고정된 상태로 양측 피스톤이 대향 패드를 누릅니다. 패드 리테이너는 몸체 슬라이드 핀과 다른 부품입니다. 이 차이와 실·부츠·가이드의 역할은 [Brembo 구조 설명](https://asia.bremboparts.com/america/en/support/car/insights/brake-caliper-technology-and-operation-324333), [Brembo 내부 부품 설명](https://asia.bremboparts.com/asiapacific/en/support/car/insights/repair-kits-for-brake-calipers-207813)을 참고했습니다.

기본 플로팅형은 지름 54 mm 피스톤 1개, 기본 고정형은 각측에 지름 54/√2 mm 피스톤 2개씩입니다. 두 기본형은 각 패드에 작용하는 유효 면적이 같아서 구조 변경 자체를 제동력 향상으로 해석하지 않습니다. `fixedPistonDiameters`는 각측에 동일하게 배치하는 지름 배열입니다.

## ABS는 캘리퍼 밖에서 압력을 조절합니다

허브의 대표 톤 링은 회전하고 휠속도 센서는 너클에 고정됩니다. 센서는 회전 상태를 제어기에 전달합니다. 외부 유압모듈의 공급·배출 밸브와 복귀 펌프가 휠별 압력을 조절합니다. 캘리퍼에 ABS 밸브가 들어 있는 것으로 표현하지 않습니다. 구성과 증가·감압의 원리는 [Bosch ABS 설명](https://www.bosch-mobility.com/en/solutions/driving-safety/antilock-braking-system/)을 참고했습니다. 실제 제품은 자기 인코더 등 다른 센싱 방식도 사용하며 여기서는 관찰하기 쉬운 일반 톤 링을 표시합니다.

## 조립 · 절개 · 분해

- **조립:** 로터 마찰판, 캘리퍼 외벽과 베어링 실이 닫힌 실제 부품 형상입니다.
- **절개:** 재료 일부를 제거해 통풍 공간·보어·실·유압실·베어링을 드러냅니다. 절단 경계에는 실제 벽 두께와 주황빛 절단면이 있습니다. 전체 케이스를 투명하게 만드는 방식이 아닙니다. 절개량을 바꾸면 실제 로터 판과 베인이 줄어듭니다. 회전부의 절개도 해당 부품과 함께 회전합니다.
- **분해:** 부품을 조립 축과 관찰 방향으로 분리합니다. 이는 관찰 위치만 바꾸며 계산 조건이나 결과를 바꾸지 않습니다.

이름표는 회전 메시 안에 붙인 글자가 아니라 화면의 수평 DOM 버튼입니다. 부품의 물리 앵커를 투영하고, 회전 대칭 부품의 앵커는 회전층 밖에 두어 공전하지 않습니다. 슬라이드와 분해 이동은 따라갑니다. 좁은 영역에서 겹칠 이름표는 우선순위로 줄이고 선택한 부품을 우선 표시합니다. 전체 부품은 앱의 부품 목록에서도 선택할 수 있습니다.

카메라는 실제 조립체의 정점 위치를 기준으로 맞춥니다. 기본 데스크톱에서는 전체 구조가 화면 높이의 약 72%를 사용하며, 바닥과 격자는 보조 배경으로 절제합니다. 선택한 부품은 은은한 재질 강조와 이름표로 구분하고 커다란 경계 상자로 구조를 가리지 않습니다. 거친 어두운 주조 몸체·가공한 은빛 마찰면·검은 고무와 마찰재를 구분합니다. 조명과 그림의 색은 실제 온도나 재료 시험 결과를 의미하지 않습니다.

## 작동 표현과 실제 수치의 경계

`wheelAngle`의 누적 rad를 그대로 사용하며 장면에서 별도 물리를 적분하지 않습니다. 로터·허브·인코더만 회전층에 있습니다. 베어링 내륜은 축대칭 대표 형상이므로 위상 구분을 따로 표시하지 않습니다. 캘리퍼·패드·센서·몸체 이름표는 휠 회전과 함께 돌지 않습니다.

압력은 계산의 Pa를 받아 화면에서 bar로 표시합니다. 1 bar = 100,000 Pa, 4 bar = 0.4 MPa, 100 bar = 10 MPa입니다. 각측 패드 힘과 총 클램프 힘은 계산 snapshot을 그대로 보관하며 그림에서 다시 계산하지 않습니다. 공급·배출 밸브와 펌프 색은 계산된 실제 상태를 읽습니다. 정지 근처의 슬립 값이 없는 상태를 0%로 꾸미지 않습니다.

미세 피스톤 변위·캘리퍼 탄성·실 변형·유압계통 컴플라이언스는 현재 물리 모델에 없습니다. 눈으로 작동 차이를 볼 수 있도록 그림의 초기 패드 간격을 3.2 mm로 확대하고 압력에 따라 닫힙니다. 화면에 **피스톤·캘리퍼 이동 간격은 확대한 작동 표현**을 항상 표시합니다. 이 이동은 측정 변위·실제 피스톤 스트로크가 아니며 제동 토크·정지 거리·열 계산을 바꾸지 않습니다. 로터가 밝게 빛나는 색이나 화염으로 온도를 과장하지 않습니다.

### 가져온 치수의 형상 표현 범위

계산 모델과 대표 조립 형상의 지원 범위는 동일하지 않습니다. 계산은 입력한 정상화 설정을 그대로 사용합니다. 현재 일반 조립 형상은 플로팅 피스톤 지름 28–80 mm, 고정형 각측 피스톤 최대 3개·지름 20–65 mm, 로터 바깥 반경 100–300 mm를 표현합니다. 패드 중심과 안쪽 반경에는 조립 공간을 위한 추가 제한이 있습니다. 예를 들어 모델이 허용한 120 mm 플로팅 피스톤이나 각측 8개 피스톤을 가져오면 그림에서는 대표 크기·배치로 표시합니다.

이때 화면에 **일부 치수는 대표 형상 · 계산값 유지**를 표시하고 해당 안내의 상세 설명에 계산 치수와 그림 치수를 구분합니다. `getDiagnostics().representation.changes`에는 변경된 필드와 원래 수치·그림 수치를 모두 제공합니다. 입력 파일이나 계산 설정은 변경하지 않습니다. 이 형상은 임의 치수의 제조 CAD 적합성·모든 피스톤 패키징 가능성을 판정하는 도구가 아닙니다.

## 장면 API와 성능

`createBrakeScene(host, {onSelect})`는 `setState(snapshot, settings, view)`, `setView(partialView)`, `resize()`, `dispose()`, `getDiagnostics()`, `getComponents()`, `focus(id)`, `setCamera(name)`을 반환합니다. CSS는 `src/scene.css`를 앱에서 별도로 불러옵니다. 카메라는 `isometric / front / rear / side / top`, 관찰 모드는 `assembled / cutaway / exploded`입니다. `getComponents()`는 안정된 ID, 이름, 설명, 재질, 회전 여부와 표시 여부를 제공합니다.

Three.js 0.180에서 회주철·가공 강철·주조 알루미늄·마찰재·고무의 표면을 구분합니다. 미세 표면은 자체 생성 텍스처입니다. 반복된 베인·톤 링·고정 금속은 병합하고 이동하는 피스톤·부츠·밸브는 독립 유지합니다. 프레임마다 새로운 형상이나 재질을 만들지 않고 변경된 상태와 카메라에만 렌더합니다. 로터 크기·캘리퍼 형식·절개 형상을 바꿀 때는 이전 자원을 해제합니다. `dispose()`는 이벤트·관찰자·프레임 예약·GPU 버퍼·재질·텍스처·컨텍스트를 정리합니다.

순수 형상 검증은 좌표·법선·UV·삼각형 면적, 절개체의 닫힌 경계와 winding, 실제 통풍 간극, 압력 표현에서 패드 접촉, 회전층과 고정 앵커, 분해 위치, 좁은 이름표 충돌, 반복 갱신과 자원 해제를 확인합니다. 이 검증은 실제 GPU 화면 품질·실측 부품 적합성·차량 제동계 인증을 대신하지 않습니다. 브라우저·독립 실행 앱 화면 검증은 통합 단계에서 별도로 수행합니다.
