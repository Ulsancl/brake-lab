# Brake Lab 1.1 상세 관찰 개선

확인일: 2026-10-02. 완성된 기존 제동 모형의 부품 관찰과 계산 근거를 더 잘 드러내는 개선이다. 물리 모형 버전은 `brake-1.0.0`을 유지한다. 차량 제동거리·ABS 결과를 바꾸기 위한 보정, 추가 마찰 또는 제어기 변경은 없다.

## 부품별로 볼 수 있는 값

| 선택 부품 | 상세 관찰값 | 해석 범위 |
| --- | --- | --- |
| 통풍 로터 | 평균 접촉 반경 선속도, 실제 제동 동력, 유입 열률, 부호 있는 열교환률, 평균 온도와 변화율 | 디스크 전체의 집중 열용량 모형. 마찰면 최고 온도 아님 |
| 캘리퍼·피스톤 | 실제 피스톤 개수, 한쪽 유압 면적, 합산 압착 유효 면적, 압력과 각 패드 수직력 | 플로팅 반작용과 고정 대향 피스톤 면적의 차이를 구분 |
| 패드 | 양면 수직력, 마찰 계수·평균 반경, 토크 용량과 실제 반작용 | 잠김에서 용량보다 작은 정지 반작용 허용. 접촉 응력·페이드 해석 없음 |
| 허브 | RPM, 각속도·각가속도, 바퀴 원주 속도·실제 제동 토크 | 솔버의 바퀴 회전 상태 |
| 허브 베어링 | 내·외륜, 케이지와 볼의 RPM, 대표 피치·볼 지름 | 외륜 고정·접촉각 0°·미끄럼 없는 기하 운동 |
| 인코더·센서 | 48T 통과 빈도, 바퀴 RPM, 원주·차량 속도와 슬립 | 이상 빈도. 측정 신호·잡음·차량 속도 추정은 미해석 |
| ABS 유압모듈·밸브 | 현재 제어 단계·압력 변화율, 목표 슬립 범위, 입구·출구 상태 | 현재 단계의 도함수. 실제 밸브 유량·압력 강하를 뜻하지 않음 |
| 펌프·호스·실·블리더 | 역할에 해당하는 캘리퍼 압력과 변화율 | 펌프 RPM·유량·누유·기포·실 변형은 미해석 |
| 기타 지지·고정 부품 | 제동계 전체의 힘·토크와 누적 에너지 | 선택 부품의 국부 응력이나 수명으로 해석하지 않음 |

표시값은 `describeBrakeDetail(partId, snapshot, settings)`에서 만들며 계산된 snapshot을 변경하지 않는다. `brakeDetail`의 숫자 관측값은 UI 표시와 검증에 공유한다. 상세한 필드·수식·단위는 [계산 모형](model.md)에 기록했다.

## 구조와 관찰

선택 부품을 별도로 자세히 관찰한 뒤 전체 구조로 돌아갈 수 있다. 이는 관찰 상태이며 제동 조건이나 보관된 비교 결과를 재계산하지 않는다. 기본 패널과 확대 화면은 같은 부품별 관측값과 해석 문구를 사용한다.

베어링 케이지의 공전과 볼의 자전은 같은 공유 운동식으로 계산한다. 고정된 절개 창에서 회전 중인 볼이 드러나는 범위가 달라진다. 인코더는 장면과 상세 계산에서 같은 48T 상수를 사용한다. 밸브와 펌프의 형상·작동 표시는 실제 모델의 열림/닫힘·감압 상태를 따라가지만 표시 이동량을 물리 스트로크나 유량으로 해석하지 않는다.

## 특히 구분할 사항

- 바퀴가 잠겨 각속도가 0이면 브레이크 토크가 남아 있어도 로터 마찰 동력은 0이다. 차량이 움직이는 동안에는 타이어·노면에서 에너지가 소모될 수 있다.
- 고정형의 실제 피스톤 총 면적과 플로팅형의 압착 유효 면적은 다른 개념이다. 기본 두 설계의 압착 유효 면적은 같으므로 제동력도 같다.
- 정지 완료는 기존 계산을 멈추는 경계다. 정지 후에도 냉각이나 압력 변화가 계속 계산되는 것처럼 표시하지 않는다.
- 디스크 평균 온도와 마찰면 최고 온도는 다르다. 대표 패드 형상에서 접촉 압력이나 허용 하중을 만들어 내지 않는다.
- 전체 에너지 표시에서 브레이크 열과 그 안의 디스크 축적 열·냉각을 이중 합산하지 않는다. 수치 잔차와 정지 잔존 에너지도 별도 항목으로 남긴다.

## 검증과 근거

새 숫자 검증은 `tests/detail-model.test.mjs`에 있다. 압력 변화와 냉각은 독립적인 해석해로 비교하고, 피스톤 면적·수직력·토크 및 기계·열수지를 복원한다. 0 입력·저속·정지·잠김 상태를 포함한다. 장면과 실제 브라우저의 추가 검증은 별도 테스트에서 수행한다.

[MathWorks Disc Brake](https://www.mathworks.com/help/sdl/ref/discbrake.html)는 압력·피스톤 면적·패드 평균 반경으로 토크를 구하고, 정지 때 외부 반작용과 마찰 용량을 구분하는 근거다. 이 앱은 실제 브레이크의 마찰면 온도 분포·접촉 압력 해석을 추가하지 않는다.

[Bosch ABS](https://www.bosch-mobility.com/en/solutions/driving-safety/antilock-braking-system/)의 센서·제어기·유압조절 구성은 구조적 역할을 확인하는 자료다. 48T, 합성 노면, 5 ms 제어 주기와 유압 시간 상수는 해당 업체의 제품 사양을 복제한 값이 아니라 앱의 공개된 대표 설정이다.

측면 관찰에서 단독 확대 중 정면으로 바꾼 뒤 복귀하는 경우, 카메라 설정·실제 자세와 이후 크기 변경까지 원래 상태가 유지되는지 확인했다. 고정형 관찰 중 플로팅형으로 바꾼 뒤 복귀할 때 새 구조의 슬라이드 핀이 표시되는지도 확인했다. 근접·모바일 스크린샷을 직접 열어 확인했으며, 두 차례의 별도 키 입력·결정적 시간 진행 검사에서도 화면 오류가 없었다.

같은 소스를 로컬 Node.js 24.12.0에서 빌드할 때 변환 후 네이티브 종료가 재현됐고, CI와 같은 24.19.0에서 정상 빌드됐다. 개발 실행환경의 최소 버전을 명시했다. 사용자용 Windows 앱은 별도 Node.js 설치가 필요 없다.

1.1.0 로컬 설치파일은 검증용 산출물이며 기존 공개 릴리스를 자동 교체하지 않는다. 수치 모델 버전과 저장 스키마는 그대로 유지한다.
