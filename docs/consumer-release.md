# Brake Lab의 제품 범위와 품질 기준

Brake Lab 1.0은 일반 사용자가 브레이크 구조를 살펴보고, 조건을 바꾸며 제동 원리를 실험하는 Windows x64용 오프라인 앱입니다. 설치 후 바탕화면이나 시작 메뉴의 Brake Lab 아이콘으로 실행합니다.

품질은 다음 네 가지 경험이 자연스럽게 이어지는지를 기준으로 평가합니다.

| 경험 | 확인할 내용 |
|---|---|
| 구조 관찰 | 조립·절개·분해 보기에서 부품의 위치와 연결 관계를 구분할 수 있어야 합니다. 부품을 선택해도 주변 구조와 시점을 유지하고, 수평 이름표와 역할·재질 설명을 읽을 수 있어야 합니다. |
| 조건 조절과 작동 관찰 | 압력·접지·패드·하중을 바꾸고 제동 움직임과 수치를 함께 볼 수 있어야 합니다. 일시정지와 이어가기는 관찰 시점을 유지하며, 조건을 바꾸면 처음부터 출발한다는 동작을 이해할 수 있어야 합니다. |
| 비교 이해 | 같은 조건에서 ABS만 바꾼 두 결과를 비교하고, 거리·잠김·열·온도의 차이를 원래 조건과 함께 읽을 수 있어야 합니다. 정지하지 못한 실험은 미완료로 구분하며, 결과를 읽은 뒤 다시 3D 관찰로 돌아갈 수 있어야 합니다. |
| 실험 보관 | 조건과 계산한 비교 결과를 파일로 저장하고 다시 열 수 있어야 합니다. 나중에 조건을 바꾸어도 이전 비교 기록을 유지하며, 손상되거나 더 새로운 저장 형식의 원문을 보호해야 합니다. |

형상은 플로팅·고정 대향 캘리퍼와 관련 부품을 설명하는 자체 제작 대표 구조입니다. 피스톤과 캘리퍼의 이동 간격은 작동을 알아보기 쉽게 확대해 표시합니다. 계산은 한 바퀴의 직선 제동, 고정 수직하중, 합성 노면 곡선, 이상적 ABS와 디스크 평균 온도를 사용합니다. 실제 차량의 하중 이동·조향·센서 보정·패드 페이드·오일 비등은 포함하지 않습니다. 관찰용 형상과 계산 결과를 실제 차량의 설계·정비·안전 판정에 사용해서는 안 됩니다. 자세한 범위는 [계산 모형](model.md)과 [부품 구조](anatomy.md)에 설명되어 있습니다.

출시 확인에는 실제 화면에서의 관찰·조작, Windows 설치와 아이콘 실행, 파일 저장·복원, 재시작, 이전 버전의 실험 유지가 포함됩니다. 자동 검사와 실제 화면 검토를 함께 사용하며, **완료한 검사와 확인한 환경은 [각 버전의 릴리스 설명](https://github.com/Ulsancl/brake-lab/releases)에서 확인할 수 있습니다.** 이 문서의 기준만으로 특정 버전의 검사가 완료되었다고 판단하지 않습니다.

한 PC에서 확인한 결과는 해당 환경에서의 실행·조작 근거입니다. 다른 그래픽 장치나 화면 배율에서 같은 성능을 보장하지 않으며, 좁은 화면 배치 검사는 모바일 앱 지원을 의미하지 않습니다. 확인한 환경과 알려진 제약을 공개하고, 이후 사용 중 발견된 문제를 개선하는 범위로 제품을 관리합니다. 설치파일의 코드 서명 유무도 릴리스 안내를 확인하세요.
