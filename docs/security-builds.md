# 안전한 빌드와 검증 산출물

웹과 Windows 패키징의 공통 빌드 도구는 검증한 소스·설정·공개 파일을 새 스테이징 디렉터리로 복사합니다. 입력 파일과 상위 폴더의 심볼릭 링크·정션·특수 파일을 거부합니다. Vite는 스테이징 안에서만 산출물을 만든 뒤 완성된 디렉터리를 게시합니다. 데스크톱 패키저에도 스테이징에 복사한 설정을 전달합니다.

브라우저·데스크톱 테스트도 새 임시 디렉터리에 기록한 다음 종료 시 기존 output 경로로 결과를 게시합니다. 기존 결과 경로에 연결 파일이 있으면 다른 위치에 기록하지 않고 실패합니다. Windows에서는 NTFS ACL로 빌드 계정과 관리자로 쓰기 권한이 제한된 전용 체크아웃이나 격리된 CI 러너를 사용하세요. POSIX에서는 도구가 산출물 부모 폴더의 소유자와 쓰기 권한도 확인합니다.

이 검증은 다른 사용자가 심어 둔 경로를 따라 비밀 파일을 포함하거나 외부 파일을 덮어쓰는 일을 막기 위한 것입니다. 검증되지 않은 소스 코드나 npm 실행 스크립트 자체를 격리하는 도구는 아닙니다.

## Windows 공식 배포

신뢰할 수 있는 Windows 릴리스 환경에 유효한 Authenticode 코드 서명 자격 증명과 타임스탬프 서비스 접근을 준비합니다. electron-builder의 지원 방식으로 서명자를 구성하고, 별도로 확인한 서명 인증서의 SHA-256 지문 64자를 `BRAKE_RELEASE_SIGNER_SHA256`으로 설정합니다. `npm run package:release`는 설치 파일과 앱 실행 파일의 서명 상태, 서명자 지문, 타임스탬프를 확인한 뒤에만 `release/signed-windows`에 결과를 게시합니다. 공식 채널에는 검증한 설치 파일과 체크섬, 기대 게시자 정보를 함께 제공합니다.

PR 및 브랜치 CI는 무서명 설치 파일을 만들어 체크섬과 고지를 확인하고 서명 검증 도구가 무서명 파일을 거부하는지도 확인합니다. 독립 실행본 전체 회귀 테스트는 같은 Electron Fuses가 적용된 별도 검증용 패키지로 실행합니다. 배포용 패키지와 웹 번들은 제품 화면에서 별도로 실행해 CSP, 테스트 전역 제외, ABS 워커 및 ASAR 시작을 확인합니다.
