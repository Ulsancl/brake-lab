두 캘리퍼의 구조와 압력·면적·토크 관계를 비교하는 대표 모형입니다. ABS는 차량 속도를 정확히 아는 이상적 제어기이며, 온도는 디스크 평균값입니다. 페이드·오일 비등·실차 정지거리 예측은 제공하지 않습니다.

이 기기에 자동 저장됨

브레이크를 직접 살펴보세요

제동 시작을 누르면 차량과 바퀴가 각각 감속합니다. 휠 슬립 0%는 구름, 100%는 바퀴 잠김을 뜻합니다.

일시정지는 현재 시점을 유지합니다. 이어서 제동으로 계속 관찰하고, 다시 출발로 처음부터 살펴보세요.

절개·분해 보기에서 패드, 피스톤, 씰, 베어링과 센서를 선택해 보세요. 작동을 확대해 보이는 움직임은 실제 변형 해석값과 구분합니다.

같은 조건으로 비교하면 현재 설정을 바꾸지 않고 ABS 켬·끔 두 시험의 실제 계산 결과를 보관합니다. ABS가 모든 상황에서 항상 더 짧게 멈춘다고 결론내리지 않습니다.

부품을 선택하면 현재의 압력·힘·회전·열 관측값이 나타납니다. 선택 부품 자세히 보기는 해당 부품을 따로 확대하고, 전체 구조로 돌아가기로 원래 시점을 복원합니다. 일반 부품 선택은 시점을 바꾸지 않습니다.

실험 저장으로 설정과 비교 결과를 파일로 보관할 수 있습니다.
