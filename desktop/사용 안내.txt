Brake Lab 1.0.0 · Windows x64

브레이크 구조 관찰·체험·비교 실험을 위한 오프라인 앱입니다.
설치파일: https://github.com/Ulsancl/brake-lab/releases/latest

1. 릴리스에서 받은 Brake-Lab-Setup-1.0.0.exe를 실행합니다.
2. 설치 위치를 선택하고 설치를 마칩니다.
3. 바탕화면 또는 시작 메뉴의 Brake Lab 아이콘으로 실행합니다.

설치한 앱은 Node.js 설치, 별도 서버 실행, 인터넷 연결 없이 사용합니다.
계산과 3D 화면은 앱에 포함되어 있습니다.

처음에는 같은 조건으로 ABS 끔/켬 비교를 실행해 보세요.
비교가 끝나면 결과가 보이는 위치로 이동합니다.
첫 문장에서 ABS를 켠 쪽이 더 짧게·더 길게 멈췄는지 또는 비교 미완료인지 확인하세요.
두 정지 거리의 차이가 소수 첫째 자리로 0.0 m이면 비슷한 거리로 설명합니다.
시작 속도·압력·노면·패드·질량 조건을 유지한 채 ABS만 바꾸어 계산합니다.
실시간 제동과 비교 계산의 결과는 별개입니다. 비교 기록은 원래 결과를 보관합니다.
일시정지는 현재 시점을 유지하며, 이어서 제동으로 계속 관찰할 수 있습니다.
비교 결과를 읽은 뒤 제동을 시작하거나 이어서 제동하면 3D 구조로 돌아갑니다.
일시정지는 관찰 중인 화면 위치를 유지합니다.
크게 보기에서도 부품 선택·역할 설명·제동 시작·재생 속도·압력과 상태를 확인합니다.
부품을 선택해도 시점을 유지합니다. 드래그로 회전하고 휠로 확대할 수 있습니다.
압력을 바꾸면 현재 제동을 멈추고 처음부터 다시 출발합니다.
비교 결과의 열·온도 설명은 보관된 두 실험의 에너지 분배를 읽습니다.
다시 출발은 처음 시점으로 돌아갑니다.
60초 안에 멈추지 못하면 정지거리·시간은 미완료로 표시합니다.

플로팅과 고정 대향 캘리퍼, 조립·절개·분해 보기에서 구조를 살펴볼 수 있습니다.
분해 간격은 분해 보기에서 조절합니다.
피스톤과 캘리퍼 움직임을 확대하는 관찰 표현은 실제 변형량 계산이 아닙니다.
노면은 높은·중간·낮은 마찰의 합성 연습 곡선이며 실제 도로 측정값이 아닙니다.
ABS가 항상 더 짧게 멈춘다고 가정하지 않습니다.

제동 시작/일시정지: 시작 버튼 또는 Space
입력 항목이나 버튼에 커서가 있을 때 Space는 해당 항목의 기본 동작을 유지합니다.
새 실험: Ctrl+N
실험 열기: Ctrl+O
실험 저장: Ctrl+S
제동 시작/일시정지 메뉴: Ctrl+Shift+P
3D 크게 보기: F 또는 Ctrl+Shift+F / 돌아가기: Esc
전체 화면: F11 / 사용 안내: F1

설정·관찰 방식과 마지막 ABS 비교 결과는 같은 Windows 사용자 계정의
앱 저장소에 자동 저장됩니다. 실시간 재생 위치는 다시 실행하면 초기화합니다.
실험 저장으로 조건과 보관한 비교 결과를 JSON 파일에 백업할 수 있습니다.
실험 JSON은 10 MiB 이하를 지원합니다. 웹 버전에서 저장한 같은 형식도 열 수 있습니다.
미래 버전이나 잘못된 결과는 현재 버전에서 덮어쓰지 않고 읽기를 거부합니다.
자동 저장을 사용할 수 없다는 안내가 나오면 종료 전에 실험 JSON으로 보관하세요.

저장 폴더: 도움말 > 저장 폴더 열기
기본 위치: %APPDATA%\Brake Lab
앱 업데이트와 일반 제거 시 이 저장 폴더는 유지합니다.
프로그램 제거: Windows 설정 > 앱 > 설치된 앱 > Brake Lab > 제거
아이콘을 다시 눌러도 같은 사용자 저장 폴더의 실행 창 하나를 앞으로 가져옵니다.

창이 숨겨지면 실시간 재생은 잠시 멈춥니다. 긴 화면 지연은 일시정지로 표시합니다.
파일 작업 중에는 완료될 때까지 기다린 후 종료하세요.

계산 범위는 한 바퀴에 배분한 질량의 직선 제동, 고정 수직하중, 이상적 ABS,
디스크 평균 온도입니다. 하중 이동·조향·실차 센서 보정·패드 페이드·오일 비등을 계산하지 않습니다.
실제 차량의 설계 승인, 브레이크 정비 또는 안전 여부를 판정하는 도구가 아닙니다.

자세한 계산 범위: 설치 폴더 resources\docs\model.md
부품 구조: resources\docs\anatomy.md
외부 라이브러리 고지: resources\docs\THIRD-PARTY-NOTICES.md
앱 자체의 저작권과 판매·배포 권리는 제품 소유자가 별도로 정합니다(UNLICENSED).
설치파일에는 코드 서명이 없습니다.
버전별 검증 결과와 확인 환경은 해당 GitHub 릴리스 설명을 참고하세요.
